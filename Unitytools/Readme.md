**简介**

本仓库为个人 Unity 管线开发工具集，主要包含自定义的 Unity 编辑器扩展及自动化脚本，旨在优化和提升日常开发与资产审查的效率。

**具体使用文档**：

https://app.notion.com/p/3df44ae1589b80a39f7de957b584f693

**环境要求**

**Unity**：Unity 2021.3 及以上版本（需支持 UI Toolkit / IMGUI）

**Maya**：Maya 2025（部分配套的 DCC 脚本依赖此版本）

**Python**：Python 3（用于运行部分 Maya 端脚本）
